# Warehouse operations

Warehouse operations is a separate industry vertical from industrial trades. It covers high-volume fulfilment, distribution and e-commerce work.

## Roles
- Warehouse operative / picker
- Packer
- Sorter
- Loader / unloader
- Inventory associate
- Returns associate
- Forklift operator
- Reach-truck operator
- Team lead

## Assignment requirements
- Site induction
- Manual handling
- Forklift licence, where the role requires it
- Reach-truck licence, where the role requires it
- Availability for the required shift pattern

## Matching rules
- Direct warehouse experience ranks first.
- Similar-industry experience can be included only when the customer enables it and explicitly accepts the industry fit.
- Equipment licences are role-specific: a picker is not automatically a forklift or reach-truck operator.

## Example request
"40 warehouse operatives for a 7-day peak period; day shift; manual handling and site induction required."

The prototype uses simulated data only. No employer, customer or worker is identified.
